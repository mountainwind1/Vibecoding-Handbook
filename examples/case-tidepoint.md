# 实战案例复盘 · TidePoint Manager（v6.1 增补的实证来源）

> 项目：全球潮汐预报点位主数据管理与质量控制平台（GIS 内部工具）。
> 技术形态：React + TS + MapLibre/Google/高德三引擎前端；FastAPI + PostGIS 后端；契约经 OpenAPI 生成前端类型。
> 方法论：Handbook **v5.3 模式**（v6 模板 + 模式声明降级：无 `.vibe/`，单人 + 偶尔并发会话）。
> 本文只收**可泛化的教训**；条目后括注该项目的决策号（D）/任务号（M-T），供追溯原始上下文。

## 一、被实战修正的手册原则（手册也要吃自己的药）

1. **v5.3 是被完整验证的推荐路径**：单人 + 少量并发会话下，`.vibe/` 机器状态层是纯开销——25 个里程碑全程未启用而协作无恙（D1）。修正：v6 模板合法降级 v5.3，经 AGENTS/CLAUDE 头部「运行模式声明」显式豁免，未声明的豁免视为违规。
2. **i18n 硬规则被显式挂起**：该条从 M1 起被连续违反（36 文件 697 处中文字面量），"预留的改造会话"从未发生——最终用户拍板整条挂起（单语言内部工具），并立禁令"不许顺手零敲碎打上 key，半套 i18n 比没有更糟"（D28→D51）。修正：硬规则要么生效、要么显式改判适用范围，**不让宪法条文变成装饰**。
3. **375px 布局基准不是通用常量**：三栏 GIS 工作台在手机上没有可用形态，"为不存在的场景做响应式是浪费"——基准替换为 1280px 并记决策、同步自查协议（D6）。修正：B3/SELFCHECK 的视口按项目模式声明取。
4. **布局断言自己也会假绿**：`scrollWidth - clientWidth === 0` 在祖先 `overflow:hidden` 时恒为 0——恰是"被裁掉但页面不滚"的形态，**它测不出自己**。该断言被记"已归零"两次（D49-2、D55-1），收口实测顶栏溢出 42px、用户菜单被裁半截，从上个里程碑起就没真正过（D59-1）。修正：双断言必须一起跑 + 登录真实角色量 + 收口重跑历史断言。
5. **契约 shared 包在跨语言项目退化为"生成"路线**：Python/TS 无法共用 zod 包，改为 Pydantic/OpenAPI 单一真相 + 生成类型（D3）；"禁止手改"没管住"忘了生成"——类型漂移横跨一整个里程碑才被发现，补 CI 契约漂移闸门（重跑生成 + `git diff --exit-code`，先验生成幂等）（D40、M7-T3）。

## 二、最贵的教训

### 静默失败与假绿（护栏 10/11 的来源）

- **"调用成功但什么都没发生"是最高发失败家族**：`catch {}` 吞掉注册失败（D61-6）、官方 API 配置"存得进去界面不变"（D62）、构建产物资源 404 使渲染恒 0 而 console 零错（D79）、可选链静默吞掉"图层没建成"（M20-T2）。规则：验可观察结果，不验调用返回；**降级可以静默，失败不可以**。
- **一次性就绪事件赌不得**：`once('load')` 等全部资源落地，一块慢瓦片就永不触发——同一个坑付了三次账（D77、D83）。规则：轮询状态谓词直到为真，事件留作幂等双保险。
- **人为补的触发步骤本身就是缺陷信号**：为验证"失焦自动保存"而手工 `focus(); blur()`，让一条真实走不通的路径测出绿灯——真实操作里输入框从未获得焦点（D86）。
- **断言先证明它能失败**：空表上的触发器拦截断言"会通过但什么都没证明"（D28）；三态筛选只测 `true`，反向写错没人知道（D33）。
- **两端各自绿 ≠ 能力可达**：别名搜索 M2 测了搜索、M4 测了导入，两端全绿——但别名表 0 行且无任何写入路径，生产里它永远搜不到东西（D27、M5-T5）。收口要走"可达性走查"。
- **管道吞退出码**：`make lint 2>&1 | tail` 让 lint 红着也能提交推送，靠 CI 兜住（实翻车一次）。

### 教训复发的治理（护栏 12 的来源）

- 并发闸门教训记了三轮 backlog 照旧漏，第四次把锁键收进一张表后归零（D56）；PG enum 迁移坑踩了四次全有留痕仍复发，收敛为共享模块后止血（M9-T5）。**同一教训复发 ≥2 次，处置从"记文档"升级为"改代码结构使违规需要绕路"**：收敛入口、反向枚举断言（枚举全部表，漏分类的 CI 必红，D59-4）、签名强制。

### 数据先行（A9 的来源）

- **dry-run 两轮救场**：国名归一清洗 dry-run 抓出缩写口径与 join fanout（计数虚高 8460 vs 真实 5473），"差点带病上线"（D81/M19-T3）。
- **权威服务实测推翻通行做法**：坐标偏移"粗矩形框判境内"经 44 点对官方转换服务实测被推翻——外国陆地与近海实测偏移全是 0，粗框让 2173 个点静默偏半公里；换多边形后错判 2173 → 24（D88）。
- **告警语义要用分布校准**：原案"区外即告警"会让 79% 对象亮黄灯——站点在岸上而模型网格只盖水面；改按距离判后 63% PASS / 37% WARN，报警指向真正的异常（D92-7）。**命中过半说明语义定反了。**
- **示例数值一律待定标**：照抄需求文档示例权重，80 分门槛结构上不可达（2.2 万条实算 0 达标、非官方来源上限 75 分）；定标后同一个 0 的含义变成"**度量正确地指出活没干**，不是度量坏了"（D51-4/D52）。
- **批量删除的完整纪律**：判据与质量检查同源、阈值服务端常量、预览→执行带 expected_count 不符即 409 一个不删；审计还抓出执行期并发移动的点按旧坐标被删（EPQ 竞态），补几何同值封条（D74）。

### 安全审计（A5 强化的来源）

8 轮审计高危 4 条全部清零，且**高危从不出现在功能逻辑里，全在"防线自身的开关与授权"上**：

| 里程碑 | 高危 | 最典型发现 |
|---|---|---|
| M4 导入 | 2→0 | 提交 TOCTOU：三并发把 200 行批次落成 600 行且三方都收到成功；导入单元格 `javascript:` URL 存储型 XSS |
| M5 导出/1.0 | 0（中 3） | 超级用户一句 `session_replication_role=replica` 绕过证据表触发器——推翻自家此前的"触发器足够"论证；未认证可推 3.15GB 落盘 |
| M8 版本管理 | 1→0 | 自定义 GUC 无权限门，**最低权角色三句 SQL 改写已发布快照**——打穿的正是本里程碑自称的命门；修复复验又抓到 `GRANT ON ALL TABLES` 把防护表授了回去 |
| M9 收口/1.1 | 1→0 | `environment` 默认 dev → 漏配的生产拿仓库里印着的公开默认密钥启动，零凭据签出 Admin 令牌（fail-open 守卫；开发机自己也一直在用默认密钥跑） |

固化的流程：独立子代理审计不自审（每轮"名不副实的防线"恰好都是本轮自己新加的控制）；修完由原审计代理**用原手法复测整条攻击链**（第一轮修复常只把攻击链挪一步）；报告三段式（发现/确认成立的防线/未覆盖面）；守卫默认值站严侧、测试矩阵必含"未配置"态（D59-2："守卫把自己的开关交给了最容易被漏掉的值"）。

### CI 与基础设施（A7 扩充的来源）

- 门禁 runner 与部署 runner 按网络条件分流后，一次全绿 90 分钟 → 4 分钟（D93）。
- `gh run rerun` 复用原 run 的 workflow 快照——修了 yml 后 rerun 等于原地踩坑，连踩两轮才识破（D93）。
- runner 根盘被缓存吃满时 job 30 秒内红，报错藏在 check-run 注解不在日志——**秒级失败先想基础设施**（D90/D93）。
- 部署纪律：先迁移后换代码（迁移增量、旧代码容忍新 schema，反过来不成立）；部署 run 永不 cancel；回滚 = sha tag + 改镜像引用；**回滚演练与备份恢复实跑过一次才算有**（M23-T2/T4）。
- 平台地基数字以官方控制台实测为准：两轮外部数据库方案死于同一个数字（第三方文章说免费 3GiB，控制台实测 0.5GB < 库的 886MB）（D66–D69）。

### 单一真相的具体形态（被引用最多的原则）

"两处同一语义必然漂移"在该项目被计数引用至少七次（D26 起）：计数与取行同函数（防"数出 1234 条导出 1189 条"）、总分由明细求和"结构上不可能对不上"（D54-1）、渲染层只留一个入口（"'知道'就是漂移的开始"，D48-1）、清洗脚本抄了一份判据 SQL 当轮就漂了（D81）。落地三形态：**复用同一函数 / 由 A 推导 B / 断言两者对撞**。
